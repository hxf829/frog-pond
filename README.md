# 🐸 青蛙池塘 Frog Pond

复刻自 **Computer History Museum** 的 *Make Software, Change the World* 展项
**Frog Pond**（Horn, Routman & Weintrop, CHI 2014）。

池塘里铺满睡莲，青蛙在上面跳，甲虫停在叶子上 —— 孩子用图形化卡片拼出一段程序，
让青蛙按程序去把甲虫吃掉。纯前端实现（HTML + CSS + 原生 JS + Canvas），
无依赖、无构建步骤。

## 在 iPad 上运行

1. **让 iPad 和 Mac 连同一个 Wi-Fi。**
2. 在 Mac 上双击 `start-server.command`，终端会打印出 iPad 的访问地址。
3. 在 iPad 的 Safari 里打开那个地址。
4. 点分享 → **添加到主屏幕**，之后可以全屏离线玩（Service Worker 已缓存）。

## 玩法

界面是**图形优先**：每张卡片有自己的图标和颜色，不认字也能靠「颜色 + 图形」配对。

### 指令卡片

| 卡片 | 图标 | 作用 |
|---|---|---|
| 跳 | 跃过一道弧 | 朝当前方向跳到相邻的一格 |
| 叫 | 声波 | 叫一声（装饰，也是演示循环的好素材） |
| 吃 | 张嘴 | 吃掉**脚下**这片叶子上的甲虫 |
| 左转 | 逆时针箭头 | 逆时针转 60° |
| 右转 | 顺时针箭头 | 顺时针转 60° |
| 转身 | 双向箭头 | 原地转 180° |
| 孵 | 蛋里的小青蛙 | 在面前孵出一只新青蛙 |
| 如果 | 菱形分叉 | 按条件决定要不要做某段程序 |
| 重复 | 回路箭头 | 把一段程序重复 N 次 |

### 插槽卡片：如果 / 重复

「如果」和「重复」的卡片下方有一个**凹槽**，可以把别的卡片**塞进去**，
塞进去的里面还能再塞 —— 无限嵌套。这是博物馆展项最核心的设计。

```
┌─ 重复 3 次 ─────────────┐
│  ┌─ 如果 脚下有虫 ────┐  │
│  │   吃                │  │
│  │   否则 → 叫         │  │
│  └─────────────────────┘  │
│  跳                       │
└───────────────────────────┘
```

- **点凹槽** → 光标进入这个凹槽，接下来点的卡片就塞进这里
- **点卡头里的条件 / 数字** → 弹出选择面板
- **点卡片右上角 ×** → 拿走这张卡片（里面的内容一起拿走）
- 顶部小按钮：撤销 / 清空 / 重置 / 声音 / 怎么玩

### 条件

| 条件 | 说明 |
|---|---|
| 脚下有虫 | 青蛙站的这片叶子上有甲虫 |
| 前面有虫 | 正前方那一格有甲虫 |
| 前面是空的 | 正前方是能落的空叶子 |
| 前面是水 | 正前方是水坑或池塘边 |

### 其它

- **▶ 运行** 逐条执行整段程序；执行到哪张卡片，那张卡片会高亮
- **⏭ 单步** 一次执行一张
- **点池塘里的格子** 可以直接把青蛙挪到相邻的格子（自由探索）
- 吃光全部甲虫即过关

### 关卡

| 关卡 | 学什么 | 甲虫 | par（完美卡片数） |
|---|---|---|---|
| 第一课：吃掉甲虫 | 跳 + 吃 | 2 | 4 |
| 第二课：水面挡路 | 转向、绕开水坑 | 2 | 9 |
| 第三课：重复 | 用「重复」代替重复劳动 | 3 | 4 |
| 第四课：如果 | 用条件让青蛙自己判断 | 4 | 6 |
| 第五课：孵出小青蛙 | 「孵」让程序自己变出帮手 | 4 | 3 |

## 和博物馆原版的对应关系

| 原版设计（CHI 2014, Iteration 3） | 本项目 |
|---|---|
| 六边形网格铺在睡莲上，标出青蛙能走的位置 | ✅ 37 格六边形池塘 |
| 甲虫停在网格上，用 `eat` 吃掉 | ✅ 甲虫落在格子上，`eat` 吃脚下 |
| `hop` / `chirp` / `eat` / `left` / `right` / `spin` / `hatch` | ✅ 全部实现 |
| 条件语句与循环（可嵌套） | ✅ 如果 / 否则 / 重复 / 嵌套 |
| 程序纵向堆叠，块与块咬合 | ✅ 纵向卡片栈 + 凹槽 |
| `start ▶` 程序括号 | ✅ |
| 运行时追踪控制流的箭头 | ✅ 当前卡片高亮并自动滚动 |
| `hatch` 孵出新青蛙，多只青蛙一起执行 | ✅ 最多 12 只 |
| 计分 | ✅ 每吃一只 +10 |
| 帮助系统 | ✅ 顶栏「?」按钮 |

### 与原版的差异

- **两种青蛙 / 两块编程面板**：原版桌面是两个面板各控制一种颜色。本项目是
  iPad 单屏，所以做成**一套程序控制所有青蛙**（含 `hatch` 出来的）。
- **甲虫飞入飞出**：原版的甲虫是持续飞入、落在格子上的。本项目保留了这个动态，
  每 5 秒飞入一只、池塘最多 6 只、满了随机一只飞走（`visitors` 可在关卡里关掉）。

## 可调参数

`game.js` 顶部：

- `POND_R` —— 池塘半径（3 = 37 格六边形）
- `LEVELS` —— 关卡：青蛙起点、甲虫位置、水坑、par、提示
- `POP` —— 甲虫数量与刷新节奏
- `FLY` —— 甲虫飞行参数
- `FROG_COLORS` / `BEETLE_COLORS` —— 配色
