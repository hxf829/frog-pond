# 🐸 青蛙池塘 Frog Pond

一个给孩子自由探索编程的池塘游戏，参考 Computer History Museum 的 Frog Pond 展项及其 CHI 2014 论文 *Programming in the Pond*。本项目针对单屏 iPad 和幼儿做了自己的调整，并非官方作品。纯 HTML、CSS、JavaScript，无构建步骤。

## 在 iPad 上玩

1. 让 iPad 和 Mac 连接同一个 Wi-Fi。
2. 在 Mac 上双击 `start-server.command`，打开终端显示的访问地址。
3. 用 iPad 的 Safari 打开地址，也可以点分享 → **添加到主屏幕**。

本地服务器禁止缓存游戏文件，重新打开或刷新页面即可加载最新版本。如果之前已经启动服务器，请先关闭旧服务器，再重新运行 `start-server.command`。旧版的游戏离线缓存会在联网打开游戏时清除，不会清除其他网站的数据。游戏现在需要联网访问本地服务器，无法离线游玩；如果改用其他服务器部署，也需要在该服务器配置 `Cache-Control: no-store` 响应头。

## 怎样玩

默认进入「自由池塘」。池塘里只有一只青蛙，甲虫会飞来飞去。大小不同的荷叶上有路线和落脚点，大荷叶上可以有多个落脚点。点下面的图案卡片，再按绿色的 ▶ 运行，让青蛙按顺序行动。青蛙面对前方相邻落脚点上的虫子时，使用「吃」就会伸出舌头把虫子拉进嘴里并得分。飞行中的虫子需要等它落下才能吃。

- **跳**：朝青蛙箭头的方向，沿路线跳到相邻落脚点；荷叶之间水面太宽、没有路线时不能跳。
- **左转 / 右转 / 转身**：改变方向。
- **叫**：让青蛙叫一声。
- **吃**：吃掉青蛙正前方相邻落脚点上的虫子。
- **如果 / 重复**：把卡片放进凹槽，尝试条件判断和循环。
- 点路线连接的相邻落脚点，也可以直接让青蛙跳过去。

卡片可以点按添加，也可以拖入程序；拖动程序里的卡片可以改变顺序。点击卡片之间的插入线，或者点一个凹槽，可以选择接下来添加卡片的位置。运行时卡片高亮，青蛙身边显示当前动作。

顶部可以选择自由池塘或五个小挑战。挑战中的目标虫会停在荷叶上，不会无限重生，吃完即可过关。清空和删除可以撤销；重置会重新开始当前玩法并清空程序。再次运行会从当前青蛙位置出发，想回到起点可使用重置。

## 自动测试

运行 `python3 tests/browser_test.py` 检查鼠标和触摸交互，运行 `python3 tests/cache_test.py` 检查缓存响应头和旧缓存清理。测试需要本机安装 Chrome，可用环境变量 `CHROME` 指定路径；模拟屏幕尺寸不能替代真实 iPad 上的测试。

## 与论文原型的主要区别

论文中的第三版使用桌面两端的独立编程面板，控制不同颜色的青蛙；本项目为了适合孩子在 iPad 上玩，使用单只青蛙和单个面板，也不提供孵化指令。论文主要描述设计和测试，不是完整规则说明；本项目的关卡和具体甲虫节奏是自己的设计。
