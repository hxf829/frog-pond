# 🐸 青蛙池塘 Frog Pond

一个给孩子自由探索编程的池塘游戏，参考 Computer History Museum 的 Frog Pond 展项及其 CHI 2014 论文 *Programming in the Pond*。本项目针对单屏 iPad 和幼儿做了自己的调整，并非官方作品。纯 HTML、CSS、JavaScript，无构建步骤。

## 在 iPad 上玩

1. 让 iPad 和 Mac 连接同一个 Wi-Fi。
2. 在 Mac 上双击 `start-server.command`，打开终端显示的访问地址。
3. 用 iPad 的 Safari 打开地址，点分享 → **添加到主屏幕**。是否可以离线取决于访问地址和 Safari 设置，见下方说明。

更新代码后，需要在联网状态下重新打开应用以更新离线缓存；如仍看到旧版本，可关闭应用后再次打开。iPad 的离线缓存要求安全上下文，普通局域网 HTTP 地址可能不能启用离线功能；可先在线游玩，并在设备上验证离线是否可用。

## 怎样玩

默认进入「自由池塘」。池塘里只有一只青蛙，甲虫会飞来飞去。点下面的图案卡片，再按绿色的 ▶ 运行，让青蛙按顺序行动。青蛙面对相邻荷叶上的虫子时，使用「吃」就会伸出舌头把虫子拉进嘴里并得分。飞行中的虫子需要等它落下才能吃。

- **跳**：朝青蛙箭头的方向跳一片荷叶。
- **左转 / 右转 / 转身**：改变方向。
- **叫**：让青蛙叫一声。
- **吃**：吃掉青蛙正前方相邻荷叶上的虫子。
- **如果 / 重复**：把卡片放进凹槽，尝试条件判断和循环。
- 点池塘里相邻的荷叶，也可以直接让青蛙跳过去。

卡片可以点按添加，也可以拖入程序；拖动程序里的卡片可以改变顺序。点击卡片之间的插入线，或者点一个凹槽，可以选择接下来添加卡片的位置。运行时卡片高亮，青蛙身边显示当前动作。

顶部可以选择自由池塘或五个小挑战。挑战中的目标虫会停在荷叶上，不会无限重生，吃完即可过关。清空和删除可以撤销；重置会重新开始当前玩法并清空程序。再次运行会从当前青蛙位置出发，想回到起点可使用重置。

## 自动测试

运行 `python3 tests/browser_test.py`（需要本机安装 Chrome，可用环境变量 `CHROME` 指定路径）。测试会启动临时本地服务器和无头浏览器，分别检查鼠标和触摸交互。模拟屏幕尺寸不能替代真实 iPad 上的触摸与离线测试。

## 与论文原型的主要区别

论文中的第三版使用桌面两端的独立编程面板，控制不同颜色的青蛙；本项目为了适合孩子在 iPad 上玩，使用单只青蛙和单个面板，也不提供孵化指令。论文主要描述设计和测试，不是完整规则说明；本项目的关卡和具体甲虫节奏是自己的设计。
