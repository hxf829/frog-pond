# 🐸 青蛙池塘 Frog Pond

复刻自 **Computer History Museum（计算机历史博物馆）** 的 *Make Software, Change the World* 展项
—— 一块「编程桌台」：池塘里有睡莲、青蛙和甲虫，孩子用图形化积木拼出程序，让青蛙按指令
移动、转向、吃掉甲虫。

纯前端实现（HTML + CSS + 原生 JS + Canvas），无依赖、无构建步骤。

## 在 iPad 上运行

1. **让 iPad 和 Mac 连同一个 Wi-Fi。**
2. 在 Mac 上双击 `start-server.command`（首次可能需要：右键 → 打开）。
   终端会打印出 iPad 的访问地址，例如 `http://192.168.0.109:8777`。
3. 在 iPad 的 Safari 里打开那个地址。
4. 点分享按钮 → **添加到主屏幕**，之后即可全屏离线运行（Service Worker 已缓存全部资源）。

> 终端窗口关闭 = 服务器停止。Mac 睡眠或换 Wi-Fi 后需重新打开。

## 玩法

界面为**图形优先**设计：每个积木都有独立的图标和颜色，小朋友不认字也能靠
「颜色 + 图形」把积木配对成程序。

#### 普通卡片

| 卡片 | 图标含义 | 作用 |
|---|---|---|
| 前进 | 大箭头指向荷叶 | 朝当前朝向前进一格（遇到水面缺口会被挡住） |
| 跳跃 | 青蛙在两只荷叶之间腾空 | 朝当前朝向跳一格；前方是缺口时，跨过缺口落到对面 |
| 左转 | 直角箭头往上再往左 | 原地旋转 90° |
| 右转 | 直角箭头往上再往右 | 原地旋转 90° |
| 换色 | 四色转盘 | 切换青蛙颜色 |
| 唱歌 | 双音符 | 唱首歌（纯装饰） |

#### 插槽卡片（如果 / 重复）—— 像博物馆展项那样「插销堆叠」

这是复刻 *Make Software, Change the World* 展项的核心：程序不是一排平铺的积木，
而是一棵可以**层层嵌套**的卡片树。「如果」和「重复」的卡片下方有一个**凹槽**，
可以把别的卡片**塞进去**，塞进去的卡片里面还能再塞 —— 无限嵌套。

```
┌─ 重复 5 次 ────────────┐
│  ┌─ 如果 前面有虫 ──┐  │
│  │   前进            │  │
│  │   否则 → 右转     │  │
│  └───────────────────┘  │
└─────────────────────────┘
```

| 卡片 | 怎么用 | 说明 |
|---|---|---|
| **如果** | 点一下卡头里的条件胶囊 | 选一个条件（前面有虫 / 前面没虫 / 前面是缺口 / 前面到边了） |
| | 点「否则」 | 多出一个「否则」凹槽，可以放另一组卡片 |
| **重复** | 点一下卡头里的数字 | 选重复几次（1–5），或者选「一直做，直到……」某个条件 |

- **点击凹槽** → 光标进入这个凹槽，接下来点的卡片就**塞进这里**。
- **点击卡头**（条件 / 数字）→ 弹出选择面板。
- **卡片右上角 ×** → 拿走这张卡片（里面的东西一起拿走）。
- **撤销 / 清空** → 顶部两个小按钮。

程序在内部会先**编译**成一串扁平指令再执行，所以嵌套多深都能正确跳转。

#### 其它操作

- **顶部三个小图标**：剩下的甲虫数 / 已排的卡片数 / 第几关。
- **▶ 运行** 逐步执行整段程序，**⏭ 单步** 一次执行一条指令。
- **点击池塘里的睡莲** 可以让青蛙直接跳过去（自由玩耍模式）——自由点击**不会**吃掉甲虫，
  甲虫只能靠执行程序时被吃掉。
- 深色的**水面缺口**（没有睡莲的格子）走不过去，只能用「跳跃」跨过。
- 吃光所有甲虫即过关；卡片数不超过每关的 par 值即为「完美！」。

#### 关卡

| 关卡 | 目标瓢虫 | 缺口 | par（完美卡片数） | 学什么 |
|---|---|---|---|---|
| 第一课：四只瓢虫 | 4 | — | 11 | 前进 / 转向 |
| 第二课：跳过水面的缺口 | 4 | 1 个 | 12 | 跳跃 |
| 第三课：更远的旅程 | 4 | 2 个 | 10 | 组合运用 |
| 第四课：重复（走一段） | 4 | — | 2 | **重复** N 次前进 |
| 第五课：如果（看情况） | 4 | — | 4 | **重复 { 如果 … 否则 … }** |

> 第四、五课不让访客瓢虫飞进来 —— 否则关卡的答案就不唯一了。

### 池塘里的瓢虫

| 规则 | 说明 |
|---|---|
| 开局 | **四种颜色各一只**（红 / 黄 / 蓝 / 白），这四只是关卡目标 |
| 之后 | 每 **5 秒**从池塘边飞入一只**随机颜色**的瓢虫 |
| 上限 | 池塘里最多同时有 **7 只** |
| 满了 | 超过 7 只时，**最早进池的那只**会随机飞走 |
| 飞行 | **同一时刻只有一只虫在飞**，其余都停在荷叶上 |

> **过关条件**：吃掉开局的四只（每种颜色各一只）。
> 飞入的「访客」是额外的，可以顺便吃掉，但不吃也不影响过关。
> 目标瓢虫不会被挤走 —— 满员时优先赶走访客，万一目标丢了会补一只同颜色的回来，
> 保证关卡永远可解。

### 会飞的虫

**同一时刻只有一只虫在飞**，其他都停在荷叶上。轮到的虫飞够了会降落，
下一只才接棒起飞。

每只虫都有一片**归属的睡莲**：

- 停在睡莲上时，青蛙靠近就会被**吓飞**（扑腾着窜到高空，躲一会儿再回来）
- 飞起来后沿一条**连续的弧线轨迹**飞行，边飞边扇翅膀，水面上留着一道随高度变淡的影子
- 飞够时间就掉头回巢，越靠近睡莲飞得越慢、越低，最后轻轻**降落**回自己的睡莲
- 飞行途中照样能吃 —— 青蛙站上那片睡莲，会「在空中逮住它」

> 归属睡莲是固定的，所以飞行只是视觉表现，不会改变关卡难度，三关始终可解。

## 文件

```
index.html      页面结构
style.css       样式（深色、适配 iPad 触控与安全区）
game.js         游戏逻辑 + Canvas 绘制
manifest.json   PWA 清单
sw.js           Service Worker（离线缓存）
icon.svg        图标
start-server.command  一键启动本地服务器
```

## 可调参数（`game.js` 顶部）

- `COLS` / `ROWS`：池塘网格大小
- `LEVELS`：关卡与甲虫位置
- `FROG_COLORS`：青蛙配色
